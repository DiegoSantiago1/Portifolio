# Documentos do portfólio

- `curriculo.html`: a fonte do currículo (edite aqui).
- `curriculo-diego-santiago.pdf`: o PDF baixado pelo botão "Baixar currículo" do site.
- `gerar_curriculo.py`: gera o PDF a partir do HTML com o Chromium do Playwright:

```bash
python assets/documents/gerar_curriculo.py
```

Depois de gerar, confira o PDF (2 páginas A4) e faça o commit dos dois arquivos.
